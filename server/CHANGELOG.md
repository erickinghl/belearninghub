## 2026-06-13 ｜ 视频上传大小限制 + 默认头像内置款式

**做了什么**
- 后台能填一个数字（如 50MB）限制视频上传大小，超过就拒绝。
- 默认头像加了 4 个内置款式可点选，也能上传自己的图。

**改了哪些文件**
| 文件 | 改动 |
|------|------|
| `app/controller/file.js` | 视频上传按 `sys_setting.video_max_mb` 限制大小；图片继续自动压缩 |
| `config/config.default.js` | multipart 硬上限放宽到 500mb（真正限制交给后台可配项） |
| `app/public/avatars/avatar-1~4.png` | 新增 4 个内置默认头像 |
| `app/public/admin.html` | 默认头像区加内置款式选择；新增"视频上传限制"卡片 |
| `database/migrations/2026-06-13_video_limit.sql` | 插入 `video_max_mb` 配置键 |

**大白话讲解**
- 图片能用 sharp 自动压小，但视频压缩要 ffmpeg（重、慢），所以视频改成"超过设定大小就拒收"，管理员可随时调这个数字。
- 注意坑：egg 框架自己有个 50MB 上传硬限制会"半路掐断"，所以把它放宽到 500MB，让真正的限制交给后台那个可配的数字。
- 设计原则：**凡是运营会想调的数字/开关，做成后台可配，别写死在代码里。**

## 2026-06-13 ｜ 后台会员管理 + VIP等级 + 充值

**做了什么**
- 后台会员列表 + 详情（每个会员做了多少题/对错率/考试/订单/笔记/收藏）。
- 会员改密码、启用/禁用。
- 会员等级（普通/VIP/SVIP）+ VIP 到期时间。
- 余额充值/扣减 + 充值流水记录。

**改了哪些文件**
| 文件 | 改动 |
|------|------|
| `app/controller/member.js` | 新增：会员列表/详情/改密/禁用/设等级/充值/总览统计 |
| `app/model/user.js` | user 加 status/level/vip_expire/balance 字段 |
| `app/model/recharge_log.js` | 新增：充值流水表模型 |
| `app/router.js` | 注册 `/admin/member/*` 路由 |
| `app/public/admin.html` | 新增"会员管理"标签页（列表+详情弹窗+等级/充值弹窗）；修了刷新后跳回课程管理的 bug |
| `database/migrations/2026-06-13_member_vip.sql` | user 加字段 + 建 recharge_log/sys_setting 表 |
| `addon/member/` | 整理成可复用功能包 |

**大白话讲解**
- 把后台当成"学员档案册 + 财务账本"：档案册记每个学员的学习行为，账本记每一笔余额变动。
- 存钱必须用 `DECIMAL(10,2)`，不能用小数（float 会算错钱）。
- 充值时"改余额 + 记一条流水"两件事一起做，否则对不上账。
- 修的 bug：刷新后台跳回课程管理——因为 tab 默认值写死了，改成用 localStorage 记住当前所在栏目。

## 2026-06-12 ~ 13 ｜ 图片自动压缩 + 默认头像 + PC宽屏 + 智能导入 + 组合题 + 登录页美化

**做了什么**（这次跨度大，合并记录）
- 上传图片自动压缩（12MB→约250KB）。
- 默认头像可后台配置，未上传头像不再空白。
- 全站 PC 宽屏适配（顶部导航栏 + 内容居中）。
- 题目智能导入（粘贴文本识别）+ 组合题（阅读理解/完型/共用选项/选词填空）。
- 登录/注册页、答题卡页、专栏页美化；我的页改页内 tab 切换。

**改了哪些文件（主要）**
| 文件 | 改动 |
|------|------|
| `app/controller/file.js` | 接入 sharp 图片压缩 |
| `app/controller/setting.js` + `app/model/sys_setting.js` | 全局配置（默认头像） |
| `app/controller/question.js` | 智能导入解析器 + 组合题解析 |
| `app/controller/practice.js` | 组合题答题判分 |
| 前端 `pages/*` 多个页面 + `components/pc-header/` | PC 适配、美化 |

**大白话讲解**
- 图片为什么慢：原图 8~12MB 没压过，局域网传当然慢；sharp 把它缩到 1280 宽、质量 80，小几十倍。
- PC 为什么之前是窄条：uni-app 默认给 H5 套了 `max-width:480px`，解除它 PC 才能铺开。
- 组合题怎么存：一个大题（材料+多个小题）整组存一行，子题放在 JSON 字段里，不动现有扁平题。

## 使用说明：怎么把数据库迁移应用到新环境

部署到新服务器时，按时间顺序执行 `database/migrations/` 下的 SQL 文件即可建表。
或直接导入完整备份 `database/egg-edu-full.sql`（含结构+数据，一步到位）。

## 2026-08-20 ｜ 后台右上角用户菜单（访问主页预览 + 改密码）

**做了什么**
- 后台管理页（admin.html）右上角原来只有"用户名 + 退出"，现在做成下拉菜单：一键新标签打开前台首页（电脑宽屏版）、一键弹出手机尺寸窗口预览前台（移动端布局）、修改管理员密码、手动刷新当前页数据、退出登录。
- 前台首页地址现在能在"站点信息"里配置（`site_home_url`），后台菜单点"访问主页"时优先用这个地址，没配就按当前后台所在主机自动拼 8080 端口。

**改了哪些文件**
| 文件 | 改动 |
|------|------|
| `server/app/public/admin.html` | 右上角加下拉用户菜单（访问主页PC/手机预览、改密码弹窗、刷新、退出）+ 站点信息表单加"前台首页地址"输入框 |
| `server/app/controller/setting.js` | `publicConfig` 增加返回 `site_home_url` 字段 |
| `app/api/request.js` | `baseURL` 从局域网测试地址改回本机 `http://127.0.0.1:7001`（收尾） |

**大白话讲解**
- **为什么要加"访问主页"按钮**：运营在后台改完课程/首页板块，总要手动开个新标签页去前台核对效果，来回切换麻烦。现在下拉菜单里点一下，直接开好前台页面；还专门做了个"手机预览"——用 `window.open` 开一个 390×844 的小窗口（iPhone 尺寸），前端的响应式布局会自动切到移动端样式，不用真掏手机出来测。
- **地址怎么来的**：`resolveHomeUrl()` 优先读后台配置的 `site_home_url`（部署到公网服务器后应该填公网地址）；本地开发没配置时，就用当前浏览器访问后台的域名/IP，自动换成 8080 端口拼出前台地址——本地和局域网测试都不用额外配置就能用。
- **改密码复用了已有接口**：没有新开后端接口，直接调用前台早就有的 `/mobile/update_password`（管理员本质上也是 user 表的一条记录，登录态通用）。
- **baseURL 那行小改动**：开发过程中一度改成局域网 IP（`172.16.0.2`）方便用手机连同一 WiFi 测试，测完改回本机回环地址 `127.0.0.1`，避免换网络环境后前端连不上后端。

## 2026-06-17 ｜ 首页内容板块（后台可配）+ 页脚改版（白色居中 + 社交图标）

**做了什么**
- 首页"最新课程"那种内容板块，现在不写死了：后台可以自由增删板块，每个板块选一种内容类型（课程 / 图书 / 题库 / 专栏），自动按类型拉对应数据；还能配标题、显示条数、排序、是否显示"查看更多"、显隐开关。想让首页同时展示课程+图书+题库，排几个板块、什么顺序，全在后台点一点。
- PC 页脚改成白色简洁居中风格（一行社交图标 → 一行快捷链接 → 联系方式 → 版权），社交图标后台可配。

**改了哪些文件**
| 文件 | 改动 |
|------|------|
| `app/model/home_section.js` | 新增"首页板块"表模型（标题/类型/条数/查看更多/排序/状态） |
| `app/controller/home_section.js` | 新增后台 CRUD：adminList / save / destroy |
| `app/controller/index.js` | 首页聚合改为循环 home_section 表，按 source_type 自动拉课程/图书/题库 |
| `app/router.js` | 注册 `/admin/home_section/{list,save,destroy}` |
| `app/public/admin.html` | 首页图标tab加"首页内容板块"管理卡片 + 编辑弹窗 |
| `database/migrations/2026-06-17_home_section.sql` | 建表 + 默认插入"最新课程"板块 |
| `pages/tabbar/index/index.vue`（前端） | 内容板块按 dataType 渲染：图书→book-list / 题库→卡片 / 课程→course-list |
| `components/pc-footer/pc-footer.vue`（前端） | 改白色居中三行布局，社交图标行 |
| `app/controller/setting.js` | publicConfig 增加 footer_socials |

**大白话讲解**
- **核心思路：把"首页长什么样"从代码里搬到数据库里。** 以前首页"最新课程"是写死在 `index.js` 里的一段代码，想加个"热门图书"得改代码重新部署。现在改成：建一张 `home_section` 表，每一行就是首页上的一个板块；后端启动时读这张表，有几行就生成几个板块，每行的 `source_type` 决定这块放课程还是图书还是题库。运营在后台加一行 = 首页多一个板块，不用动代码。
- **一个接口喂三种内容**：板块的"类型"字段决定后端去哪张表查数据——`book` 去图书表、`testpaper` 去题库表、其他去课程表。前端拿到数据后看 `dataType` 字段，决定用图书卡片、题库卡片还是课程卡片来渲染。所以一套板块逻辑能展示完全不同的内容。
- **排序和显隐**：`sort` 大的排前面（和首页宫格图标一个套路），`status=0` 直接不出现在首页——运营想临时下掉某个板块，点一下"隐藏"就行，不用删数据。
- **页脚为什么单独配社交图标**：链接、联系方式之前已经能配了，这次把"微信/微博/抖音"这类社交入口也做成后台可配的一行图标——同样是"运营要改的别写死"原则。
- **延续老规矩**：能不建表就不建表，这次因为"首页有几个板块"是结构化的列表数据（每个板块有多个属性、还要排序），键值表 `sys_setting` 装不下，所以才新建了 `home_section` 表——和当初建"宫格图标"表 `nav_icon` 是同一个判断逻辑。

## 2026-06-13 ｜ 学习时长统计（心跳上报）

**做了什么**
- 用户看课程时，前端每60秒发一次"还在学"的心跳，后端累加学习时长。
- 后台会员详情显示：累计学习、今日学习、各课程学习时长分布。
- 总览加"学习时长(时)"。

**改了哪些文件**
| 文件 | 改动 |
|------|------|
| `app/model/study_log.js` | 新增：学习时长表模型 |
| `app/controller/study.js` | 新增：心跳接口 `/mobile/study/heartbeat` |
| `app/controller/member.js` | detail 加学习时长统计 + 各课程分布；overview 加总学时 |
| `app/router.js` + `config/config.default.js` | 注册 study 路由 + auth.match |
| `api/api.js`（前端） | 加 studyHeartbeat 接口 |
| `pages/course/course.vue`（前端） | 课程页挂心跳定时器（进页开始/离开停止/页面隐藏暂停） |
| `database/migrations/2026-06-13_study_log.sql` | 建 study_log 表 |

**大白话讲解**
- 学习时长后端算不出来，必须前端"埋点"上报。我们用**心跳**：在课程页每60秒发一次信号，后端往"今天这门课"的记录加60秒。
- 表设计巧思：用 `(用户+课程+日期)` 唯一键，每人每天每门课只存一行（心跳来了就累加），而不是每60秒存一行——否则一天就几百行，数据爆炸。**聚合存储，不要流水存储。**
- 防作弊：单次心跳最多累加120秒（前端就算改成发"我学了1万秒"也被后端卡住）。**永远不要相信前端传的数字，后端要兜底校验。**
- 暂停逻辑：页面切到后台/最小化时（document.hidden）不上报——人没在看就不算时长，数据才准。

## 使用说明：怎么把数据库迁移应用到新环境

部署到新服务器时，按时间顺序执行 `database/migrations/` 下的 SQL 文件即可建表。
或直接导入完整备份 `database/egg-edu-full.sql`（含结构+数据，一步到位）。
